My Project Name is FitLog 

Short Description:
FitLog is a modern, high-performance fitness web application designed as a no-nonsense gym companion. It allows users to browse comprehensive exercise libraries, build custom workout plans, track exercise durations and burned calories, and manage their daily fitness routines seamlessly.

Technologies Used:
* Framework:* Next.js (React)
* Styling:* Tailwind CSS
* State Management:* React Context API
* Deployment:* Vercel

5 Key Features:
. Interactive Exercise Library:* Browse through a wide range of detailed workouts complete with instructions, difficulty levels, target muscle groups, and equipment info.
. Dynamic Workout Planner:* Add workouts to "Today's Plan" or save them for later, with real-time tracking of total exercises, minutes, and burned calories.
. Smart Sorting & Filtering:* Easily sort your workout lists dynamically by duration, calories, or ratings to optimize your daily training schedule.
. Completion & Progress Tracking:* Mark workouts as completed on-the-go to stay motivated and keep track of your daily fitness milestones.
. Responsive Dark-Themed UI:* Built with a sleek, gym-inspired dark aesthetic and fully responsive layout optimized for all devices.
